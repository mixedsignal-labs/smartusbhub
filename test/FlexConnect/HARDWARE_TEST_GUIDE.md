### 1.1 硬件连接

#### 基本连接
- **USB转串口线**：连接到PC，用于通信
- **电源**：确保设备正常供电

- **P0**：车机USB端口（输入）
- **P1**：PC端口（ADB调试）

- **P3**：U盘2端口

## 四、硬件验证（使用逻辑分析仪）

### 4.1 GPIO信号监控

参考 `TRUTH_TABLE.md` 中的真值表，使用逻辑分析仪监控以下信号：

#### 输出信号（MCU控制）
- **DATA_SEL1** (PB4)：一级MUX选择
- **#DATA_OE1** (PB6)：一级MUX使能（低有效）
- **DATA_SEL2** (PB7)：二级MUX选择
- **#DATA_OE2** (PB8)：二级MUX使能（低有效）
- **DUT_VBUS_EN** (PA2)：车机VBUS使能
- **UDISK1_VBUS_EN** (PA6)：U盘1 VBUS使能
- **UDISK2_VBUS_EN** (PA7)：U盘2 VBUS使能

#### 输入信号（状态检测）
- **DUT_VBUS_FAULT** (PA3)：车机VBUS故障
- **UDISK1_VBUS_FAULT** (PA5)：U盘1 VBUS故障
- **UDISK2_VBUS_FAULT** (PA4)：U盘2 VBUS故障
- **KEY1/KEY2/KEY3**：按键输入

### 4.2 验证要点

1. **模式切换时序**：
   - 切换时先断开所有连接（OE=1, VBUS_EN=0）
   - 等待互锁延迟（100ms）
   - 再使能目标路径

2. **模式真值表**：
   - PC模式：DATA_SEL1=1, OE1=0, OE2=1, DUT_VBUS_EN=1
   - UDISK1模式：DATA_SEL1=0, OE1=0, DATA_SEL2=0, OE2=0, UDISK1_VBUS_EN=1
   - UDISK2模式：DATA_SEL1=0, OE1=0, DATA_SEL2=1, OE2=0, UDISK2_VBUS_EN=1

3. **互锁验证**：
   - 切换过程中，确保没有两个VBUS同时使能
   - 确保没有两个MUX路径同时导通

## 五、常见问题排查

### 5.1 连接问题
- **问题**：无法连接设备
- **排查**：
  - 检查USB转串口驱动是否安装
  - 检查COM端口号是否正确
  - 检查是否有其他程序占用串口
  - 尝试重新插拔USB线

### 5.2 模式切换失败
- **问题**：模式切换后读取模式不正确
- **排查**：
  - 检查硬件连接是否正常
  - 使用逻辑分析仪检查GPIO信号
  - 检查互锁延迟是否足够
  - 查看串口调试信息

### 5.3 按键无响应
- **问题**：按键按下后无反应
- **排查**：
  - 检查按键是否使能（`btn_enable`）
  - 检查按键硬件连接
  - 使用逻辑分析仪检查按键信号

### 5.4 故障检测异常
- **问题**：故障状态显示异常
- **排查**：
  - 检查VBUS故障检测引脚连接
  - 检查是否真的存在故障（过流、短路等）
  - 验证故障检测逻辑是否正确

## 八、关键逻辑测试重点

### ⚠️ 你担心的这些逻辑，重点测试：

#### 1. 上电默认模式逻辑
**测试步骤**：
1. 设置默认模式为 UDISK1
2. **断电重启**（必须！）
3. 检查上电后是否自动切换到 UDISK1

**预期行为**：
- 上电后，如果：
  - 没有设置默认电源标志 → 使用 `flexconnect_default_mode`
  - 设置了默认电源标志 → 使用默认电源状态对应的模式
  - 启用了掉电恢复 → 优先使用保存的模式

#### 2. 掉电恢复逻辑
**测试步骤**：
1. 启用掉电恢复
2. 切换到 UDISK2 模式
3. **断电重启**
4. 检查是否恢复到 UDISK2

**预期行为**：
- 如果 `poweroff_recover == 1`：
  - 从 `channel_power_status` 恢复模式
  - ch0=1 → PC模式, ch1=1 → UDISK1, ch2=1 → UDISK2
- 如果 `poweroff_recover == 0`：
  - 使用上电默认模式

#### 3. 恢复出厂设置逻辑
**测试步骤**：
1. 设置一些非默认值（默认模式、掉电恢复等）
2. 执行恢复出厂设置
3. 检查所有参数是否恢复为默认值

**预期行为**：
- `flexconnect_default_mode` → `MODE_PC`
- `poweroff_recover` → `0`（禁用）
- `channel_power_status` → 全部清零
- 当前模式 → 应用默认模式（PC）

#### 4. 优先级逻辑验证
**测试场景**：
1. 设置默认电源标志（ch1=UDISK1）
2. 启用掉电恢复
3. 切换到 UDISK2 并保存
4. **断电重启**

**预期行为**（按优先级）：
1. **最高优先级**：默认电源标志 → 使用 UDISK1
2. **次优先级**：掉电恢复 → 使用 UDISK2
3. **最低优先级**：上电默认模式 → 使用 PC
